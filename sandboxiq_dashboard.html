// What We Detect

Full-Stack Behavioral Analysis

🐳
Docker Sandbox Isolation
Files are executed in a locked-down Docker container with no network, read-only filesystem, and strict resource limits. Auto-deleted after execution.
🤖
ML Anomaly Detection
Isolation Forest model trained on behavioral features: process creation rates, syscall patterns, network connection attempts, and file I/O anomalies.
📡
Network Traffic Monitor
Captures all outbound connection attempts, DNS queries, C2 beaconing patterns, and data exfiltration attempts from within the sandbox.
⚙️
Process Behavior Tracking
Logs all spawned processes, parent-child relationships, command-line arguments, privilege escalation attempts, and process injection events.
📁
File System Activity
Monitors reads, writes, deletes, and renames — with special attention to sensitive paths like System32, startup folders, and user profile directories.
🛡️
MITRE ATT&CK Mapping
Detected behaviors are automatically mapped to MITRE ATT&CK tactics and techniques for standardized threat reporting.
